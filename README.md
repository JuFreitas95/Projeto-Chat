 💬 Chat em Tempo Real

Aplicação de chat com comunicação em tempo real utilizando WebSocket, permitindo troca de mensagens dinâmica entre usuários.

🧠 Sobre o projeto

Este projeto consiste em uma aplicação de chat desenvolvida com foco em comunicação em tempo real, utilizando WebSocket para atualização instantânea das mensagens sem necessidade de recarregar a página.

A aplicação simula um ambiente de troca de mensagens entre usuários, explorando conceitos modernos de frontend integrado com backend.

 🚀 Tecnologias

* HTML
* CSS
* JavaScript
* WebSocket
  
 ⚙️ Funcionalidades

* ✔️ Envio e recebimento de mensagens em tempo real
* ✔️ Atualização automática da interface
* ✔️ Comunicação cliente-servidor via WebSocket
* ✔️ Interface interativa

 🔗 Arquitetura

* Frontend: Interface do usuário e interação
* Backend: Gerenciamento de conexões WebSocket
* Comunicação em tempo real entre cliente e servidor

 📌 Objetivo

Praticar desenvolvimento de aplicações com comunicação em tempo real e integração entre frontend e backend.

 📈 Aprendizados

* Comunicação em tempo real com WebSocket
* Integração frontend + backend
* Manipulação de eventos assíncronos
* Estrutura de aplicações interativas
